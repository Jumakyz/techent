# CodeFix Express — Product Design & Specifications

This package contains:
- `CodeFix_Express_Product_Design_Specifications.pptx` — presentation covering all 7 assignment areas.
- `VPC_CodeFix_Express.mmd` — Mermaid VPC diagram source, ready to render in GitHub.
- `index.html` — lightweight MVP landing-page prototype you can publish with GitHub Pages.
- `README.md` — setup and rendering instructions.

## Render the VPC in GitHub
1. Create a repository or open your existing repository.
2. Upload `VPC_CodeFix_Express.mmd`.
3. Create `VPC.md` and paste the file content inside:
   ```mermaid
   [paste the Mermaid source here]
   ```
4. Commit the file. GitHub renders Mermaid diagrams in Markdown files.

## Publish the MVP mockup with GitHub Pages
1. Upload `index.html` to the root of a GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
4. Use the generated GitHub Pages URL in the presentation.

## Important
This is a prototype, not a live booking/payment system. The form currently demonstrates the intended interaction and does not process real payments or store requests. Prices and response times are proposed MVP specifications and should be validated in a pilot.
